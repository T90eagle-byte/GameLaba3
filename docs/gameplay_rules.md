## Уточнение по заданиям и display-layer

`check_task` проверяет признаки выбранного существа по `task_markers`. Происхождение существа сейчас не проверяется отдельным backend-признаком: стартовое существо и существо после эксперимента оцениваются одинаково, если их признаки совпадают с маркерами задания.

Формулировки заданий должны быть конкретными по признакам и не обещать обязательное происхождение через скрещивание/мутацию, если backend это не проверяет. Использовать стиль «Найдите», «Отберите», «Предъявите» и называть конкретные значения: зелёная окраска, раздвоенный плавник, гладкий панцирь, высокая скорость и т.д.

GUI может показывать display-only подсказки, портреты, бейджи и уведомления о задачах, уже завершённых backend после действия. GUI не принимает бизнес-решения и не заменяет `pkg_genetics_game`.
