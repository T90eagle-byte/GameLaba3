# Демонстрационный набор ЛР3

Набор создаётся отдельно от production seed и не удаляет существующих пользователей, лаборатории или данные Docker volume. Игровые изменения выполняются через `PKG_GENETICS_GAME`; скрипты используют чтение Oracle только для поиска кандидатов и проверки результата.

## Запуск

При доступной Oracle и заполненном `python_client/.env` выполните из корня репозитория:

```powershell
.\.venv\Scripts\python.exe database\scripts\create_lr3_demo_data.py
.\.venv\Scripts\python.exe database\scripts\check_lr3_demo_data.py
```

Первый запуск дополняет только недостающие сущности через package API. Повторный
запуск подготовленного набора не создаёт пользователей, лаборатории, сессии,
существ или эксперименты. Скрипт не очищает таблицы и не меняет обычный seed.

## Учётные записи

| Логин | Пароль | Лаборатории |
|---|---|---:|
| `lr3demoalpha` | `DemoLR3Pass2026` | 5 исторических v1 + 1 витрина v3 |
| `lr3demobeta` | `DemoLR3Pass2026` | 5 исторических v1 + 1 витрина v3 |

Каждый пользователь видит только свои лаборатории. Для проверки одновременной работы войдите под разными логинами в разных браузерах или профилях браузера.

После подготовки исторического набора и двух v3-витрин в текущем
воспроизводимом состоянии имеется 16 application session rows: по восемь для
каждого demo-пользователя. Ручной browser-smoke может создать дополнительные
записи, но generator при повторном запуске их не плодит.

## Что показать преподавателю

- 10 исторических v1-лабораторий и две отдельные v3-витрины;
- селекционные линии с сохранёнными скрещиваниями;
- выполненные задания;
- в v3-витрине: скрещивание, облучение, комбинированный опыт и гибридизация;
- v3-гибрид с 19 каноническими генами и без архетипа;
- различающиеся Монеты, рейтинг, число существ и история экспериментов;
- сохранность данных после выхода и повторного входа.

Направленные production-мутации для v3 намеренно не добавляются в демонстрационный набор: текущий v3-каталог пуст, а безопасные мутагенные операции остаются доступны. Исторические v1-лаборатории и их направленные мутации не изменяются.

`check_lr3_demo_data.py` выводит число пользователей, лабораторий, сессий, существ, экспериментов, выполненных заданий и видов. Дополнительно он проверяет v3-архетипы, 18 морфологических признаков, четыре вида v3-экспериментов и гибриды. Утилита завершится с ошибкой, если не выполнен хотя бы один минимальный критерий допуска.

## Подтверждение сохранности в Oracle

Повторно выполните readiness-проверку после logout/login или перезапуска web-приложения. Данные хранятся в Oracle: `users`, `sessions`, `labs`, `creatures`, `experiments` и `lab_tasks`; обычный перезапуск приложения их не удаляет.
