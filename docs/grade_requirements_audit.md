## 5. Что можно честно говорить на пересдаче

Проект уверенно закрывает уровень 3: 6 видов, признаки цвет/размер/крылья/питание, гены/аллели/генотипы, phenotype cache, скрещивание, probabilities, preview 3 вариантов, задания и стартовая генерация.

Проект защищаемо закрывает уровень 4: неполное доминирование, кодоминирование, сцепленные гены, directed mutations, случайные mutagens, RADIATION/CHEMICAL с риском, история экспериментов, `rating_events`, заказы клиента и эволюционная линия через последовательность экспериментов.

Инженерные расширения сверх базового уровня 4: многопользовательские сессии, защита чужих лабораторий, справочники `ref_*`, строгие FK, smoke-tests `01..11`, LR2-compatible package API и Python-клиент без gameplay SQL.

## 6. Риски для защиты

- Если преподаватель ждет буквальную “волко-собаку”, объяснять адаптацию: проект не про одну породу, а про многовидовую “БиоСборку”; заказы клиента реализованы через задания и markers.
- Если спросят про экосистему, честно сказать: это roadmap уровня 5, текущая версия надежно закрывает 3/4.
- Если спросят про совет по этике, показать штрафы за мутагены и `rating_events`, но не утверждать, что совет уже реализован.
- Если спросят, почему Python не считает генетику, объяснить архитектуру: бизнес-логика вынесена в Oracle PL/SQL package, клиент только вызывает API и отображает данные.
- Если спросят про 3 варианта потомства, показать `preview_offspring_options`: он возвращает ровно 3 stateless preview-варианта по умолчанию.
- Если спросят про происхождение существа в задании, уточнить: текущие задания marker-based и проверяют признаки, strict provenance оставлен как отдельный будущий backend-трек.
