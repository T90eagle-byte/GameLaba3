# AI Context: БиоСборка

## 1) Проект

БиоСборка — учебная игра-симулятор генетического конструктора.

Архитектура:
- backend полностью на Oracle PL/SQL;
- центральный backend-пакет: `pkg_genetics_game`;
- Python — только GUI-клиент (подключение к Oracle, вызовы API, отображение данных).

## 2) Текущий статус

- Backend strict-pass завершен.
- `pkg_genetics_game` (spec/body) компилируется на Oracle.
- `USER_ERRORS` для `PKG_GENETICS_GAME` пустой.
- Smoke-tests `01..07` проходят с `Failed: 0`.
- Backend на текущем этапе не менялся.

## 3) GUI состояние

Реализованы:
- Auth;
- Lab Selection;
- Main Window Shell;
- вкладка «Существа»;
- вкладка «Генетический эксперимент»;
- вкладка «Мутации».

По вкладке «Мутации» добавлены:
- блок целевых генов мутации;
- подсказки совместимости мутации и существа;
- фильтрация совместимых существ;
- человекочитаемые ошибки `ORA-20043` и `ORA-20045`.

`python -m compileall python_client` проходит успешно.

## 4) Ограничения

- Python не переносит бизнес-логику из PL/SQL.
- Python не считает генетику, мутации, экономику, задания и статистику.
- Python не использует `dbms_output`.
- Все игровые операции идут через API `pkg_genetics_game`.

## 5) Следующий шаг

Следующий GUI-этап:
- вкладка «Задания» или
- вкладка «История экспериментов».

- Пользовательский интерфейс и тексты — на русском.
- Английский только для технических имен, API, полей БД и enum-значений.
