# Сценарий защиты: «БиоСборка» v3

Продолжительность: около пяти минут. Используйте подготовленную историю, а не
пытайтесь во время защиты повторять случайные операции.

## Перед показом

1. Проверьте `/health/live` и `/health`.
2. При доступной Oracle выполните `check_runtime_readiness.py`.
3. Подготовьте вход `lr3demoalpha` / пароль из `docs/lr3_demo_data.md`.

## Маршрут

1. Войдите под demo-пользователем и откройте «Альфа: витрина v3».
2. На обзоре покажите Монеты, рейтинг и сохранённое имя лаборатории.
3. Откройте список существ: стартовые существа имеют архетипы, карточки
   используют составной SVG renderer.
4. Откройте detail одного существа. Покажите выраженные морфологические
   признаки, а не технические ID аллелей.
5. Откройте «Задания». Объясните, что v3 оценивает выраженный phenotype в
   Oracle; историческая v1 совместимость сохранена отдельно.
6. В «Экспериментах» переключите историю: «Скрещивание», «Мутаген»,
   «Скрещивание + мутаген» и «Гибридизация» уже представлены в витрине.
7. Откройте готового гибрида из истории. Покажите, что это отдельный вид без
   архетипа и что его renderer построен по 19 canonical genes.
8. Откройте историю рейтинга и кратко покажите последствия операций.
9. Скажите: бизнес-логика, проверки доступа, наследование и экономика
   выполняются в Oracle PL/SQL package `pkg_genetics_game`; web только вызывает
   package API и отображает результаты.

## Если live-операция неудобна

Не повторяйте случайный мутаген или гибридизацию. Откройте сохранённую v3
history и detail готового результата. Для доказательства backend используйте
`database/tests/30_v3_end_to_end_acceptance_smoke_test.sql`: он проверяет тот
же connected lifecycle с временными fixtures и cleanup.

## Короткие ответы

- **Почему гибрид нельзя скрестить?** Это правило v3 package; гибрид можно
  исследовать и мутировать, но не использовать как родителя.
- **Почему preview не показывает процент?** Он показывает random examples;
  точная вероятность полного организма не выдаётся за результат preview.
- **Где сохраняется игра?** Лаборатория, существа, Задания и история находятся
  в Oracle и переживают перезапуск клиента.
- **Как обновляется существующая схема?** Только non-destructive versioned
  update с marker 14, без удаления пользователей и лабораторий.
