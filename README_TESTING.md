# БиоСборка: тестовая Docker-сборка

Эта сборка запускает Oracle и web-игру в Docker. Устанавливать Python, Oracle,
SQL Developer или выполнять SQL-файлы вручную не требуется.

## 1. Что понадобится

- Windows 11 x64;
- Docker Desktop с включённым режимом **Linux containers**;
- не менее 8 ГБ свободной оперативной памяти и около 10 ГБ на диске;
- интернет для первой загрузки образов Oracle и Python.

Распакуйте ZIP в простой локальный путь без сетевого диска, например
`C:\BioSborka`. Не запускайте проект прямо из архива.

## 2. Подготовка `.env`

Откройте PowerShell в папке проекта и выполните:

```powershell
Copy-Item .env.example .env
```

Для локального теста значения из примера работают как стартовые. Перед
передачей папки другим людям замените оба пароля и `FLASK_SECRET_KEY`.
Используйте в Oracle-паролях 12–64 латинских букв, цифр или символов `_`.

## 3. Первый запуск

Самый простой вариант — дважды щёлкнуть `start-game.cmd`.

Эквивалентная команда PowerShell:

```powershell
docker compose up --build -d
```

Первый запуск Oracle обычно занимает несколько минут. Игра откроется, когда
сервисы `db` и `web` станут `healthy`, а `db-init` завершится с кодом `0`:

```powershell
docker compose ps
```

Адрес игры:

```text
http://127.0.0.1:8000
```

Проверка готовности:

```text
http://127.0.0.1:8000/health
```

Ожидаемый ответ содержит `"app":"ok"` и `"database":{"ok":true}`.

Oracle не публикуется на хост: к нему подключаются только контейнеры внутри
Compose-сети. Web доступен только локально на `127.0.0.1`.

## 4. Логи и диагностика

Статус контейнеров:

```powershell
docker compose ps
```

Последние сообщения всех сервисов:

```powershell
docker compose logs --tail=200
```

Отдельные логи:

```powershell
docker compose logs db --tail=200
docker compose logs db-init --tail=200
docker compose logs web --tail=200
```

В первом запуске дождитесь сообщения `Schema installation completed
successfully` в `db-init`. Полный backend test runner при обычном старте не
запускается.

## 5. Остановка и повторный запуск

Остановить без удаления пользователей и лабораторий:

```powershell
.\stop-game.cmd
```

или:

```powershell
docker compose stop
```

Повторный запуск:

```powershell
.\start-game.cmd
```

При повторном запуске схема распознаётся по внутреннему marker и SQL-файлы не
применяются заново. Данные находятся в именованном Docker volume.

## 6. Полный сброс

`reset-game.cmd` удаляет volume и **безвозвратно стирает все игровые данные**.
Скрипт требует ввести слово `DELETE`:

```powershell
.\reset-game.cmd
```

Ручной эквивалент:

```powershell
docker compose down -v --remove-orphans
docker compose up --build -d
```

## 7. Типичные проблемы

### Docker недоступен

Запустите Docker Desktop и убедитесь, что выбран режим Linux containers. Затем
проверьте `docker info`.

### Порт 8000 занят

Измените `WEB_PORT` в `.env`, например:

```text
WEB_PORT=8080
```

После этого используйте адрес `http://127.0.0.1:8080`.

### Первый запуск долго остаётся `starting`

Oracle Free — крупный образ. Подождите 5–10 минут и проверьте
`docker compose logs db --tail=200`. Не запускайте reset во время первичной
инициализации.

### После изменения пароля база не запускается

Пароль сохраняется вместе с существующим volume. Верните исходный `.env` или,
если данные не нужны, выполните полный сброс.

## 8. Маршрут ручного тестирования

1. Откройте `/health` и убедитесь, что Oracle доступен.
2. Зарегистрируйте нового пользователя и войдите.
3. Создайте и переименуйте лабораторию.
4. Проверьте обзор и список существ.
5. Откройте карточку существа с фенотипом и генотипом.
6. Проверьте и сдайте заказ клиента.
7. Получите три preview-варианта и создайте потомка.
8. Купите и примените мутацию.
9. Примените `RADIATION` или `CHEMICAL`.
10. Проверьте эволюционную линию и историю рейтинга и денег.
11. Выйдите и войдите снова, убедившись, что лаборатория сохранилась.

## 9. Что прислать разработчику при ошибке

- скриншот страницы или сообщения Docker Desktop;
- вывод `docker compose ps`;
- вывод `docker compose logs --tail=200`;
- содержимое ответа `/health`;
- версию Docker Desktop и Windows;
- какой шаг инструкции выполнялся перед ошибкой.

Не отправляйте файл `.env`: он содержит локальные пароли и Flask secret.
